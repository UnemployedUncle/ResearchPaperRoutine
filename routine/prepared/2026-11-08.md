**2026년 11월 8일(일, 한국) | Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks | RAG-01 | 핵심 질문: 왜 모델 내부의 지식과 검색한 문서를 함께 사용하는가?**

이전에 RAG-01의 자료가 여러 차례 제공되었지만 명시적인 독해 완료는 확인되지 않았습니다. 오늘은 밀린 분량을 늘리지 않고, **원문 1~2쪽에서 두 가지 기억의 역할을 설명할 수 있는지 점검하는 30분 복습형 독해**를 준비했습니다. 학습 자료를 준비한 것과 실제 읽기 완료는 구분합니다.

## 1. 3분 복습 | 기억은 어디에 존재하는가?

**회상 질문:** 모델이 어떤 회사의 계약 조건을 예전 내용으로 답했다면, 모델 파라미터를 고치는 방법과 계약 문서를 교체하는 방법은 각각 무엇을 바꾸는 걸까요?

우선 답을 하나로 결정하지 말고, '정보를 저장하는 곳'과 '정보를 답변에 사용하는 과정'을 서로 구분해 보세요. 오늘 원문에서 그 차이를 확인합니다.

## 2. 20분 원문 읽기 | 두 종류의 기억과 Figure 1

**고정 원문:** [arXiv PDF v4 — Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks](https://arxiv.org/pdf/2005.11401v4) · [버전 및 발표 이력](https://arxiv.org/abs/2005.11401)

- **최초 발표:** 2020년 5월 22일(v1). **읽는 수정본:** 2021년 4월 12일(v4).
- **확인된 원문 범위:** PDF **1쪽 Abstract와 §1 Introduction 첫 문단**, PDF **2쪽 Figure 1과 그림 바로 아래 Introduction 본문**. Figure 1의 검색기·문서 인덱스·생성기·Marginalize 흐름을 원문 페이지 이미지로 확인했습니다.

**① 5분 — PDF 1쪽 Abstract와 Introduction 첫 문단.** 초록에서 '모델 내부의 지식이 충분할 때에도 남는 한계'와 '외부 기억을 결합하는 목적'에 해당하는 문장을 각각 찾으세요. 단순히 더 많은 문서를 제공하는 것이 아니라 **지식 수정·근거 확인·지식 활용**의 문제를 저자들이 어떻게 구분하는지 표시해 보세요.

오늘 필요한 첫 개념인 **Parametric Memory(파라미터 기반 기억)**는 학습 과정에서 모델의 가중치에 내재화된 정보를 의미합니다. 특정 사실을 수정하려면 일반적으로 문서 파일 하나만 바꾸는 것으로는 모델 가중치가 변경되지 않습니다.

두 번째 개념인 **Non-parametric Memory(비파라미터 기반 기억)**는 RAG에서 모델의 가중치 바깥에 놓인 문서 검색 인덱스를 의미합니다. 이 논문은 Wikipedia의 문서 벡터 인덱스를 사용합니다. 인덱스의 내용을 갱신할 수 있더라도 최신 문서가 실제 검색되고 정확히 활용되는지는 별도의 문제입니다.

**② 10분 — PDF 2쪽 Figure 1.** 먼저 왼쪽에서 오른쪽으로 **질문 \(x\) → Query Encoder \(q(x)\) → MIPS와 Document Index → 후보 문서 \(z_1,\dots,z_K\) → Generator → Marginalize → 출력 \(y\)**를 눈으로 따라가세요. 원문 그림에는 검색기가 'Non-Parametric', 생성기가 'Parametric'으로 명시되어 있습니다. 아래의 세 관찰 지점에만 집중합니다.

| 원문 그림의 요소 | 직접 확인할 질문 |
| --- | --- |
| Query Encoder와 Document Index | 질문 표현과 문서 표현은 각각 어디에서 오는가? |
| 검색된 복수의 \(z\) | 왜 하나의 문서만 가져오는 구조로 그리지 않았을까? |
| Generator와 Marginalize | '문서를 찾음'과 '그 문서를 활용해 답의 확률을 계산함'은 어떻게 다른가? |

Figure 1의 **점선 역전파 경로**도 찾아보세요. 그림은 검색과 생성을 연결한 학습 경로를 설명하지만, **모든 문서 인덱스가 항상 자동으로 수정된다는 뜻은 아닙니다.** 실제로 이 논문의 §2.4에서는 문서 인코더와 인덱스를 고정해 학습한다고 설명합니다. 오늘은 §2.4를 정독하지 않고 위치만 알아둡니다.

**③ 5분 — PDF 2쪽 Figure 1 아래 Introduction 본문.** 저자들이 REALM·ORQA의 추출형 질의응답에서 **seq2seq 기반 생성**으로 연구 범위를 확장하려 한 이유를 찾아보세요. 그런 다음 Figure 1에 제시된 질의응답·사실 검증·Jeopardy 질문 생성의 **서로 다른 출력 형태**가 어떤 공통 구조를 사용하는지 확인합니다.

**원문 주장과 실무 판단의 경계:** 저자들은 검색 기반 기억과 생성 모델의 결합이 지식 집약적 과제에서 유효하다는 실험 결과를 보고합니다. 그러나 **외부 문서만 최신으로 교체하면 모든 답변이 최신·정확해진다**는 보장은 이 그림에서 나오지 않습니다. 그 결론을 원문에 덧붙이지 마세요.
