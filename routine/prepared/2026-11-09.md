## 2. 20분 원문 읽기 | Provenance와 Figure 1

**고정 원문:** [Retrieval-Augmented Generation — PDF v4](https://arxiv.org/pdf/2005.11401v4) · [arXiv 버전 이력](https://arxiv.org/abs/2005.11401)

**연도 구분:** 최초 공개 **2020년 5월 22일(v1)**, 이번에 읽는 수정본 **2021년 4월 12일(v4)**. 읽을 곳은 **PDF 1쪽 Abstract와 §1 Introduction 첫 문단**, **PDF 2쪽 Figure 1 및 그 아래 §1 Introduction 본문**입니다. 인쇄된 쪽수와 PDF 뷰어 쪽수는 이 범위에서 일치합니다.

**① 5분 — PDF 1쪽: 문제를 제기한 문장 찾기.** Abstract에서 *providing provenance*와 *updating their world knowledge*를 언급하는 부분을 찾아 밑줄을 긋습니다. 이어 Introduction 첫 문단에서 기존 모델이 지식을 확장·수정하기 어렵고, 예측의 이유를 확인하기 어려우며, 환각을 생성할 수 있다고 지적하는 부분을 읽으세요. 저자들이 **연구 문제를 제기하는 문장**과 그 문제를 **완전히 해결했다는 증거**를 구분해 표시해 보세요.

오늘의 첫 개념 **Provenance(근거·출처 추적)**는 답변이나 판단이 어떤 정보에 기반하는지 확인할 수 있는 성질입니다. 외부 문서를 검색하면 후보 자료를 조사할 수 있지만, 이것만으로 생성 문장의 각 주장이 그 자료에 의해 뒷받침된다는 뜻은 아닙니다.

**② 10분 — PDF 2쪽: Figure 1의 연결을 눈으로 확인하기.** 그림의 **Query Encoder → MIPS → Document Index와 여러 문서 \(z_i\) → Generator → Marginalize → \(y\)** 흐름을 따라가세요. 이때 아래 세 관찰 지점에만 집중합니다.

| 그림에서 볼 위치 | 원문을 보면서 답할 질문 |
| --- | --- |
| Document Index와 검색 결과 \(z_1,\ldots,z_K\) | 화면에 확인 가능한 것은 **후보 문서**인가, 이미 검증된 최종 답변인가? |
| Generator와 문서별 경로 | 생성기는 질문과 후보 문서를 조건으로 무엇을 계산하는가? |
| Marginalize와 출력 \(y\) | 여러 문서에 따른 예측을 결합하는 것과 **문장별 출처를 확정하는 것**은 같은가? |

오늘의 두 번째 개념 **Latent Variable(잠재변수)**는 학습 데이터에 정답 레이블로 직접 주어지지 않았어도 결과의 확률 계산에 관여하는 변수입니다. Figure 1에서 검색된 문서 \(z\)가 이에 해당하고, 저자들은 여러 후보 문서를 조건으로 한 생성 예측을 **주변화(marginalization)**합니다. 이는 확률 계산 방법이지, 특정 문장에 대한 법적·사실적 증빙 판정 장치는 아닙니다.

Figure 1 상단의 **점선 역전파 화살표**도 확인하세요. 이 그림은 학습 신호와 추론 흐름을 설명합니다. 그림에 없는 '근거 사실 검증기'를 있다고 추정하지 않는 것이 오늘의 중요한 관찰입니다.

**③ 5분 — PDF 2쪽: 논문의 주장과 평가 범위 분리하기.** Figure 1 아래 §1 Introduction 마지막 문단에서 저자들이 실제로 강조한 결과를 확인하세요. Open-domain QA와 지식 집약적 생성에서 보고한 개선과, 외부 비파라미터 기억을 교체해 지식을 갱신할 수 있음을 보였다는 주장을 구분해 봅니다.

**읽기 질문:** 이러한 결과가 '모든 답변의 각 문장에 올바른 근거가 붙는다'는 결론까지 뒷받침할까요? 논문이 실제로 보고한 성과의 범위를 넘어 답하지 말고, 근거를 Introduction에서 확인해 보세요.

## 3. 5분 이해 기록 | 주장·원문 위치·남은 의문

아래 세 칸은 **직접** 채웁니다. 답안을 미리 완성하지 않아도 됩니다.

| 기록 항목 | 직접 작성할 내용 |
| --- | --- |
| **핵심 주장 한 문장** | 왜 모델 내부의 지식과 검색 가능한 문서를 함께 사용하는가? |
| **근거가 있는 원문 위치** | PDF 1쪽 Abstract/Introduction 또는 PDF 2쪽 Figure 1의 어떤 요소인가? |
| **남은 질문 하나** | 검색 후보의 출처와 생성 답변의 근거를 검증하는 데 무엇이 더 필요한가? |

**자기 점검 1:** 검색된 문서 목록이 보인다면, 생성된 모든 문장의 출처가 검증되었다고 말해도 될까요?

**자기 점검 2:** Figure 1의 Marginalize는 여러 문서의 **예측 확률**을 결합할까요, 여러 문서의 **진위 여부**를 확정할까요?
